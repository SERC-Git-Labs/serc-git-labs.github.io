# Additional Files

This directory contains additional files that are not part of the Jekyll site but are used to help create assets for the site.

| File | Description |
| ---- | ----------- |
| `reference.pptx` | PowerPoint file used as a template when creating the different PowerPoint slideshows. See [Pandoc manual](https://pandoc.org/MANUAL.html#powerpoint-layout-choice) for more information. |
