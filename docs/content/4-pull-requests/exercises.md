# Lesson 4 Exercises

## Exercise 1: Create a Pull Request
### Goal
Propose branch changes through GitHub.

### Steps
1. Create a branch
2. Make a change
3. Commit the change
4. Push the branch
5. Open a pull request

## Exercise 2: Review a Pull Request
### Goal
Practice giving useful review feedback.

### Steps
1. Open a partner’s pull request
2. Review the changed files
3. Leave at least one comment
4. Approve or request changes

## Exercise 3: Update and Merge a Pull Request
### Goal
Revise a pull request and complete the workflow.

### Steps
1. Respond to feedback
2. Make a new commit
3. Push to the same branch
4. Merge the pull request
5. Delete the branch

## Final Challenge
Complete the full team workflow from branch creation to merged pull request.

## Reflection Questions
- Why are pull requests useful?
- What makes a pull request easy to review?
- What should you check before merging?
