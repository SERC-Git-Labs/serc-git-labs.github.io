# Lesson 4: Pull Requests, Team Workflow, and Best Practices

## Overview
Learn how teams propose, review, update, and merge work using pull requests.

## Learning Objectives
- Explain why teams use pull requests
- Create a pull request on GitHub
- Review and comment on a pull request
- Update a pull request after feedback
- Merge a pull request
- Apply Git and GitHub best practices

1. Why Pull Requests Matter
2. Creating a Pull Request
3. Reviewing Pull Requests
4. Updating a Pull Request
5. Merging Pull Requests
6. GitHub Best Practices
7. Common Professional Workflows
8. Final Integrated Practice
