# Lesson 1: Git Basics, Local Repositories, and Intro to Remotes

## Overview
Introduction to Git, GitHub, repositories, commits, and basic remotes.

## Learning Objectives
- Explain the difference between Git and GitHub
- Create a repository with `git init`
- Clone a repository with `git clone`
- Stage and commit changes
- View project history
- Push changes to GitHub

## Lesson Sections
1. What Is Version Control?
2. Git vs. GitHub
3. Setting Up Git
4. What Is a Repository?
5. Starting with `git init`
6. Starting with `git clone`
7. Basic Git Workflow
8. Viewing History
9. Intro to Remotes
10. Hands-On Practice
