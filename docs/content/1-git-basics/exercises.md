# Lesson 1 Exercises

## Exercise 1: Create a Local Repository
### Goal
Create a new project using `git init`.

### Steps
1. Create a folder
2. Initialize Git
3. Add a file
4. Stage the file
5. Commit the file
6. View the history

### Expected Outcome
A local Git repository with at least one commit.

## Exercise 2: Clone a GitHub Repository
### Goal
Start from an existing GitHub repository.

### Steps
1. Copy the repository URL
2. Clone the repository
3. Open the cloned folder
4. Check the remote
5. Make a small change
6. Commit and push

### Expected Outcome
A pushed change visible on GitHub.

## Reflection Questions
- When should you use `git init`?
- When should you use `git clone`?
- What is the difference between committing and pushing?
