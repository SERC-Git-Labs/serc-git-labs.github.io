# Lesson 2: Branching, Merging, and Working Safely

## Overview
Learn how to use branches to work safely, merge changes, and resolve simple conflicts.

## Learning Objectives
- Explain why branches are useful
- Create and switch branches
- Make commits on a branch
- Merge a branch into `main`
- Resolve a simple merge conflict
- Undo common local mistakes

## Lesson Sections
1. Why Branches Matter
2. Understanding the Main Branch
3. Creating and Switching Branches
4. Working on a Branch
5. Merging Branches
6. Merge Conflicts
7. Undoing Local Mistakes
8. Hands-On Practice
