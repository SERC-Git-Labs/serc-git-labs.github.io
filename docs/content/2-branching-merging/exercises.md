# Lesson 2 Exercises

## Exercise 1: Create and Merge a Feature Branch
### Goal
Use a branch to make and merge a change.

### Steps
1. Create a new branch
2. Make a change
3. Commit the change
4. Switch back to `main`
5. Merge the branch
6. Delete the completed branch

## Exercise 2: Resolve a Merge Conflict
### Goal
Create and resolve a simple conflict.

### Steps
1. Create two branches
2. Edit the same line differently on each branch
3. Merge one branch into the other
4. Open the conflicted file
5. Resolve the conflict
6. Stage and commit the resolution

## Reflection Questions
- Why are branches useful?
- What does merging do?
- What causes a merge conflict?
