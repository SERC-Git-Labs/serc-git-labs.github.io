# Lesson 3: GitHub, Remotes, and Collaboration

## Overview
Go deeper into GitHub repositories, remotes, syncing work, and simple collaboration.

## Learning Objectives
- Navigate a GitHub repository
- Create a GitHub repository
- Connect a local repository to GitHub
- Clone existing repositories
- Use `fetch`, `pull`, and `push`
- Understand basic collaboration practices
