# Lesson 3 Exercises

## Exercise 1: Create and Connect a GitHub Repository
### Goal
Create a remote repo and connect it to local work.

### Steps
1. Create a GitHub repository
2. Add it as a remote
3. Push local commits
4. Confirm the files appear on GitHub

## Exercise 2: Clone and Update a Repository
### Goal
Work from an existing remote repository.

### Steps
1. Clone a repository
2. Make a small edit
3. Commit locally
4. Push to GitHub

## Exercise 3: Pull a Partner’s Change
### Goal
Practice syncing remote changes.

### Steps
1. Partner pushes a change
2. Pull their change
3. Make another change
4. Push your change

## Reflection Questions
- What is the difference between `fetch` and `pull`?
- Why might a push be rejected?
- What does an upstream branch do?
